Ferramenta madura e distribuível: busca instantânea sobre PDFs locais e na nuvem (OneDrive/Google Drive via rclone), indexação incremental e pacotes prontos para instalar. Na versão 0.5.1.

Recursos

Busca instantânea por nome
Indexa nuvem (OneDrive/GDrive via rclone)
Delta sync — só atualiza o que mudou
Progresso visual da indexação
Roda em i3, Sway, GNOME, KDE, XFCE
Pacotes .deb + instalador Windows

O código está em 0.5.1 (pyproject), mas o CHANGELOG para em 0.2.0 e o badge do README diz GTK4 enquanto as dependências reais são PyQt6 (houve migração de toolkit não refletida). Não é bug — é doc desatualizada, mesma classe do gate que o Zen combate.

Próximo passo, se reabrir: alinhar README/CHANGELOG ao estado real (Qt, 0.5.1) e travar a versão do doc via §Documentos 12.
